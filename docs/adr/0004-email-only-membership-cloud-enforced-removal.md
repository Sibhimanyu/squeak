# Email-only membership; the cloud enforces removal

People join a Pond only by an email invite tied to their account, and a Pond has three plain roles: Owner, Member and
Viewer. Removing or leaving takes effect in the cloud at once on every device; the Pond key rotates
later, when the Owner's Mac is next online.

We dropped long codes, short codes, copied links, per-browser web guests, presets, per-Member switches,
per-Duck locks and machine grants because each added states that broke or went stale, and the owner found sharing
neither smooth nor stable (2026-11-26). We chose cloud-enforced removal over waiting for the Owner's Mac because a
removal that depends on a sleeping laptop does not feel final; key rotation still needs the Mac, so until it runs the
relay's refusal is what keeps a removed person out. The relay never holds a Pond key: invites stay keyless and the
Owner's Mac seals the key to each new device.
