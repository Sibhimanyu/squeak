# Tools open lists; items open as tabs

In the Mac's new layout every page (Dashboard, Room, Duck) has the same tool rail. A tool opens a one-shot list, and
the item you pick opens as a Pond-scoped tab in the centre; only the Terminal uses a side pane. We chose this over a
side work pane per tool (built in 2.34.x) because a pane squeezed the chat, stacked header rows, needed a pin to
survive Duck switches, and duplicated its own switcher. Tabs give one place where opened things live, and the round
Duck circles plus item pills keep the look Squeak's own.
