# Squeak brand

The brand kit, Edition 01 (October 2026). The rules live in
[`DESIGN.md`](../DESIGN.md) (§1 the brand, §3.1 colour, §4.1 type, §6.1–6.2
logo and mascot, §9 brand copy); this folder holds the files they point at. Interface rules (state colours, surfaces, components, motion)
are in DESIGN.md too, not here.

| Path | What it is |
| --- | --- |
| `guidelines/squeak-brand-guidelines.pdf` | The guidelines, 14 pages: identity, logo, colour, type, voice, mascot, applications, production. Read this one. |
| `guidelines/squeak-brand-guidelines.ai` | The editable Illustrator master: live text, native paths, one layer per page. Install `fonts/` before opening. |
| `logo/svg/` | Vector logos. `ink` files are for light grounds, `paper` files for dark. |
| `logo/png/` | Transparent PNGs at fixed sizes, for slides and chat. Never place them on a baked-in square. |
| `logo/source/squeak-duck-approved-source.png` | The approved artwork, unmodified. The vectors are traced from it; it is the reference of record. |
| `logo/squeak-logo-library.jsx` | Illustrator script that draws the vector duck (used to build the guidelines). |
| `fonts/` | Figtree, Inter and JetBrains Mono, each with its SIL OFL licence and source (`fonts/README.md`). |
| `tokens/squeak-brand.css`, `.json`, `.ase` | Brand colours, type scale and logo geometry. The `.ase` is a swatch file for Adobe apps. |

## Which logo file

| Need | File |
| --- | --- |
| The duck at 48 px and up | `squeak-duck-full-color` |
| 24 to 47 px | `squeak-duck-compact` |
| 16 to 23 px | `squeak-duck-silhouette` |
| One flat colour | `squeak-duck-mono-ink` (on light), `squeak-duck-mono-paper` (on dark) |
| Duck and name side by side | `squeak-lockup-horizontal-{ink,paper}` |
| Duck over name, square spaces | `squeak-lockup-stacked-{ink,paper}` |

File names follow `squeak-<asset>-<variant>-<tone>-<width>.<ext>`.

## Rebuilding the guidelines

The `.ai` and `.pdf` are generated by an ExtendScript build kept outside the
repo (`.context/brand-work/` in the workspace that made it). Edit the
document in Illustrator directly for small changes; keep this folder and
DESIGN.md in step when a rule changes.
